# 工作流程

此目錄收錄隨附的工作流程定義與探索型錄。正式的使用者、撰寫、CLI 與 API 文件刊載於[工作流程文件](https://github.github.io/spec-kit/workflows/overview.html)。

## 目錄內容

| 路徑 | 用途 |
| --- | --- |
| `speckit/workflow.yml` | 完整 SDD 交付週期 |
| `bugfix/workflow.yml` | 錯誤評估、修復與驗證 |
| `assess/workflow.yml` | 構想評估流程 |
| `catalog.json` | 第一方工作流程型錄 |
| `catalog.community.json` | 社群工作流程型錄 |
| `step-catalog.json` | 第一方自訂步驟型錄 |
| `step-catalog.community.json` | 社群自訂步驟型錄 |

社群型錄是探索管道，不是程式碼審查或安全背書。安裝與使用前，使用者必須自行審查工作流程定義、參照的指令碼、自訂步驟套件與覆蓋層。
