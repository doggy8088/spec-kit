# 預設集

此目錄包含第一方預設集資產、型錄資料，以及建立預設集的鷹架。正式的使用者與作者文件發佈於[預設集指南](https://github.github.io/spec-kit/presets/overview.html)。

## 目錄內容

| 路徑 | 用途 |
| --- | --- |
| `catalog.json` | 第一方預設集型錄 |
| `catalog.community.json` | 社群探索型錄 |
| `lean/` | 內建的精簡流程預設集 |
| `constitution-sync/` | 內建的選用憲章同步預設集 |
| `scaffold/` | 撰寫預設集時可複製的範例套件 |
| `self-test/` | 預設集貢獻的儲存庫測試夾具 |

社群預設集由各自的維護者獨立維護。納入型錄並非程式碼審查、安全性背書或支援承諾；使用者在安裝第三方預設集之前必須自行審查。
