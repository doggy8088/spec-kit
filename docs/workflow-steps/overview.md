# 工作流程步驟

工作流程步驟提供可重用的可執行行為單元。工作流程以 `type:` 選取步驟類型並提供其設定；工作流程引擎擁有排序、執行狀態、檢查點與繼續執行。

## 內建與自訂類型

內建類型隨 Spec Kit 出貨。它們會呼叫命令與提示詞、執行 shell 任務、在審查關卡暫停，並表達分支、迴圈與扇出。省略 `type` 會選取 `command`。`workflow` 呼叫會在同一次執行中組合另一個已安裝的工作流程。

自訂步驟套件加入以 Python 實作的類型。每個套件提供一個類型鍵，與使用它的工作流程分開安裝。當可重用的可執行行為不符合既有類型時，請使用自訂類型；當組合既有步驟已足夠時，請使用工作流程。

## 安裝自訂步驟之前

請在安裝與使用前審查原始碼、相依性與副作用。安裝會驗證並複製套件，而不會匯入其 Python。之後的 `specify workflow add`、`run` 與 `resume` 會載入已安裝的步驟套件，以你的權限執行匯入時期的程式碼，即使特定步驟尚未被選取執行亦然。

社群型錄清單是探索中繼資料，不是程式碼稽核、背書或安裝許可。請以 `specify workflow step catalog list` 檢查使用中的來源。

## 在工作流程中使用步驟

審查並安裝自訂類型後，請選取其確切的類型鍵：

```yaml
steps:
  - id: check
    type: my-step
```

額外的設定與輸出取決於類型。工作流程引擎會執行該步驟；沒有獨立的步驟執行命令。
