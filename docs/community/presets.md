# 社群預設集

尋找可依你的流程調整 Spec Kit 範本、命令與術語的預設集。依用途、作者或標籤搜尋，再開啟預設集查看其需求與發行詳細資訊。

> [!NOTE]
> 社群預設集由各自作者獨立建立與維護。維護者僅確認型錄項目完整且格式正確，不審查、稽核、背書或支援預設集程式碼本身。安裝前請先檢視預設集原始碼，並自行斟酌使用。

本目錄是依據[社群預設集型錄](https://github.com/github/spec-kit/blob/main/presets/catalog.community.json)產生的。顯示的版本是型錄所列的發行版本，而非儲存庫的即時發行版本。社群型錄僅供探索。

Star 數量是上次文件建置時擷取的 GitHub 儲存庫總數。同一儲存庫的預設集共用同一個數字；Star 數量並非安全性背書。
